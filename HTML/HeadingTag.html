Heading Tag

Syntax of HTML

Opening Tag <h1> then content : "This is content" Then closing Tag </h1>

Combination of Opening tag,closing tag and content it's called "HTML Element".

What is the Heading Tag? The Heading Tag is used to define headings in an HTML page.

We have six heading element form </h1> to </h6>: <h1>, <h2>, <h3>, <h4>, <h5>, and <h6>.

</h1> Heading Tag

</h1> is most important and it's largest Heading Element. It's used for a define main heading of the Page.

Note: </h1> Heading tag is used one time on one single html page.

</h2> Heading Tag

</h2> is less important then </h1> and it's smaller then </h1> . It's used for a define subheading of the Page.

Note: </h2> Heading tag is used Multiple time in single html page.

</h3> Heading Tag

</h3> is less important then </h2> and it's smaller then </h2> . It's used for a define subheading of the Page.
