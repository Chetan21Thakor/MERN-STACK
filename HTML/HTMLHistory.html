HTML History

HTML : HTML Stand for a Hyper Text Markup language.

Hyper Text Meaning : Hyper text meaning a text which contain the link of the another text.

Markup Language Meaning: It's Way of giving instruction to a computer how my content is organized or display on web browser.

The concept of Hyper Text is Proposed by Ted Nelson in 1960s.

In 1980s ,Tim Berners -Lee introduce a World wide web(WWW) and create first html website.
