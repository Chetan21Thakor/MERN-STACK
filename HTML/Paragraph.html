What is Paragraph Tag?

A Paragraph means <p>Tag define the Paragraph. It's used when we want ot display textual data in our web page.

We can use multiple <p> tag in one page.

Note: <p> is block level Element. Block Level element Means : it's occupied a entire with on web page and browser add one line space before and after it.

Note: don't nest one block level element inside another block level element otherwise it's not good for SEO and user it's make confusion for User and Seo.
