Object In Javascript

Object

What is Object and why we need Objects?

Object is collection of the key value pair or is store related information as set of key value pair.

When we want to represent any real world entities in program or map a any real world object or thing in code then we need a object to represent it.

Object Creation

how to create a Object

There are to way of creating a Object.

  1. Literal or singleton Object
  2. using Object construction method

1.Literal or singleton Object

            
              let obj={
                      name:"chetan",
                      age:24,
                      isMarried:false,
                      "full Name":"Thakor Chetan"
                  }

2. Using Object construction method

            
              let obj1 = new Object({ name: "Charvi", age: 22, isMarried: false });

              console.log(obj1, typeof obj1);

Singleton Object

A Object is single, unique object created once in your code.

Creating an object using literal syntax is considered a singleton because it creates one specific object instance that is not used as a template to create others.

You can store anything in Javascript object for example

array,function,object,properties.

Note: ❑ Objects are mutable.

            
              let allThingObject = {
                arr: [1, 2, 3, 4, 5],

Object Properties and Method

Object Properties : A just give information. it's define inside a object.

Object Method : A function which is define inside a object is called "method of object". It's call using only that particular object.

How Access Object each properties and Method

To Access a Object properties or method two notation are used.

  1. Dot Notation
  2. Square Notation

1. Dot Notation

            
              let person = {
                name: "chetan",
                age: 24,
                isMarried: false,
                "full Name": "Thakor Chetan",

                showPerson:function(){
                  console.log(this.name);
                  console.log(this.age);
                  console.log(this.isMarried);
                  console.log(this["full Name"]);
                }
              };

              let name =person.name;
              let age = person.age;
              let isMarried=person.isMarried;

              person.showPerson();

Using dot . notation you can access properties and method of the object.

Object and Array Destructuring

When we want to access and store the value of the Object Properties or Array element as variable not every time access it's using a dot notation and array element using it's index value that time Object and Array Destructuring is used.

Object Destructuring

In Object Destructuring order is not matter you can access object any key using it. but make sure you are write exact same key which present in object. 

            
              let person = {
                name: "chetan",
                age: 24,
                isMarried: false,
                "full Name": "Thakor Chetan",

                showPerson:function(){
                  console.log(this.name);
                  console.log(this.age);
                  console.log(this.isMarried);
                  console.log(this["full Name"]);
                }
              };

              const {name , age}=person;
              console.log(`Name is : ${name} and age is : ${age}`);
