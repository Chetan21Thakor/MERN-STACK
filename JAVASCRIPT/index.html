Variables and Data Types

Variable is name of the memory location it's just like a container which can hold or store data.

There are three types of variables in JavaScript: var, let, and const.

way of the creating a variable in js.

let variableName = value;

var variableName1 = value;

const variableName2 = value;

// real example

let name = "John";

var age = 30;

const PI = 3.14;

let : Variable cannot re-declared but can be updated. it's has a block scope

var : Variable can be re-declared and updated. it's has a global scope

const : Variable cannot be re-declared and updated. it's has a block scope

Browser console work on REPL(Read Evaluate Print Loop) means it read the entire statement or expression then evaluate it and print the output in console then loop.
just because of this we can write a n number of the code in browser console and it will execute one by one and print the output in console.

Rules for naming a variable in js:

  • Identifier name is always start from the _,$,small or capital latter only.
  • it's can contain a _,$,small or capital latter,0-9 digit only.
  • you cannot use reserved keywords as identifier names.
  • identifier names are case-sensitive.
  • you cannot use spaces in identifier names.
  • you cannot use special characters other than _ and $ in identifier names.

JavaScript has 7 data types:

1. Number
it's store positive negative integers and floating-point numbers

2. String
it's store a sequence of characters

3. Boolean
it's store true or false values

4. Null
it's represent intentional absence of any object value

5. Undefined
it's represent a variable that has been declared but not assigned a value

6. BigInt
it's store large integers that are too big for the Number type

7. Symbol
it's a unique identifier used to define properties in objects

Javascript is a dynamically typed language. it's mean you no have to define it's data type when you declare a variable.
