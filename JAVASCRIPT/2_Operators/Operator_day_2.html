Arithmetic Operator

List of the Arithmetic Operator

  1. "+" : It's add two Number for example " 2 + 5 = 7"
  2. "-" : It's Subtract right hand side Number from left hand side number for example " 5 - 3 = 2"
  3. "*" : It's Multiply two Number for example " 2 * 5 = 10"
  4. "/" : It's Divide Number for example " 12 / 5 = 2"
  5. "%" : It's return remainder for example " 13 % 5 = 2"
  6. "**" : It's return a^b for example" 2 ** 3 = 8"

Example

                
                    console.log("10 + 4" + " = " + `${10 + 4}`);//* ans : 14

                    console.log("10 % 4" + " = " + 10 % 4);//* ans : 2

Comparison Operator

List of Comparison Operator

Comparison Operator are used to compare two value or variable. it's compare a left side value with right hand side value.

Note : Comparison Operator Always Return a Boolean value.

for example

let x = 29; let y = 12; console.log(`x > y ${ x > y}`);//* ans : true
  1. ">" : it's check or compare a left side value is greater then right hand side value if yes then it's return a True.

  2. "<" : it's check or compare a left side value is lesser then right hand side value if yes then it's return a True.

  3. "<=": it's check or compare a left side value is lesser or Equal then right side value if yes then it's return a True.

  4. ">=": it's check or compare a left side value is greater or Equal then right side value if yes then it's return a True.

  5. "==" : it's check or compare a left side value is Equal to right side value if yes then it's return a True. it's lossy equal to operator it's not check it's data type it's just check only value if both value are same then return true.

  6. "!=" : it's check or compare a left side value is Not Equal to right side value if yes then it's return a True. it's lossy Not equal to operator it's not check it's data type it's just check only value if both value are not equal then return true.

  7. "===" : it's check or compare a left side value is Equal to right side value if yes then it's return a True. it's strictly equal to operator it's check it's data type first if data type is Different then also return false then it's check value if both value are same then return true.

  8. "!==" : it's check or compare a left side value is Not Equal to right side value if yes then it's return a True. it's strictly Not equal to operator it's check it's data type first if data type is Different then also return true then it's check value if both value are not equal then return true.

Example

                
                   // * Comparison Operator

                   // * it's always return a boolean value only.

                    let x = 29;
                    let y = 12;

                    console.log(`x > y ${ x > y}`);//* ans : true
                    console.log(`x< y ${ x< y}`);//* ans : false
                    console.log(`x< y ${ x<= y}`);//* ans : false
                    console.log(`x > y ${ x >= y}`);//* ans : true
                    console.log(`x == y ${ x == y}`);//* ans : false
                    console.log(`x === y ${ x === y}`);//* ans : false
                    console.log(`x !== y ${ x !== y}`);//* ans : true
                    console.log(`x != y ${ x != y}`);//* ans : true

Lossy Equal to internally work on the strictly equal to and type coercion. If left side value data it's Different from right hand side value data then it's convert any one of them data type automatically.after doing type coercion it's check both value are equal or not. If both value are equal then it's return true otherwise false.

Logical Operator

List of the Logical Operator.

  1. && (AND) : If all condition are true then only then it's return true.
  2. || (OR) : If all condition are false then only then it's return false.
  3. ! (NOT) : it's flip True to False and False to True

Logical Operator always return a boolean value true or false. it's used to combine multiple condition.

1. && (AND)

If all the condition are return True then only then it's return True. If any one condition return a False then it's return False.

Logic Table of the && (AND)
Input A Input B Output
True True True
True False False
False True False
False False False
2. || (OR)

If all the condition are return False then only then it's return False. If any one condition return a True then it's return True.

Logic Table of the || (OR)
Input A Input B Output
True True True
True False True
False True True
False False False
3. ! (NOT)

it's flip True to False and False to True.

Logic Table of the ! (NOT)
Input A Output
True False
False True

Ternary Operator

Syntax of Ternary Operator

            
                (condition) ? st1 : st2 ;
             
            
                let age=19;

               let result= (age >18 ) ? "adult": "not adult";

               console.log(result);

Ternary is Operator. it's not statement.After checking condition then based on condition it's return a result.

How Ternary Operator work?

step 1 : It's check condition.

step 2 : If condition return True then it's return result which immediately come after a question mark(?).
If condition return false then it's return a result which immediately come after colon (:).
