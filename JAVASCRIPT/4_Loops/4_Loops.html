First we are learn about a For loop.

What is a For Loop?
Ans:A For Loop is a Looping statement which used to do any task on loop.

For Loop is Most of the time used when a number of the Iteration are fixed.

Syntax of For Loop

for (Initialization ; condition ; updating){

// some task

}

Inside for loop
First is a initializing Statement which define where the loop is start. it's starting pointe of the for loop.
Second is condition Statement which Define a where the loop is end. it's ending pointe of the loop.
Third is updating statement which define how the iterator is updated.

Iterate Means executing or run the loop.
Iterator is a Variable this define inside a loop . Which is responsible to initialization of the loop and updating of the loop.
IterationMeans one single run of the loop. Which start from initialization ,then check condition then execute a loop task it's one Iteration. second Iteration is start from updating the iterator.

How the For Loop work?

Ans: First when the for loop execution is start then Initialization statement run or executed first to initialize Iterator.
Second ending condition is checked if it's return a true then for loop task is executed. If this condition return a false then loop is end.
Third When after the checking the condition or when it's returning a true for loop is executed then updating a iterator then second time condition is check and so on.... until conditional statement not return a false.

// some task

   i++; updation statement
}

Here initialization statement is out-side the while loop. it's initialize a iterator.

then while condition is checked if it's return true then while loop task is executed.

updation statement write inside a while at the end of the while loop. it's update a iterator.

How While Loop is executed?

ans: first initialization statement run first to initialize a iterator only for one.

then While condition is checked if it's return the true the while loop is executed otherwise not.

Updation Statement is at the end of the while loop it's update a iterator. then second time while condition is checked then while loop is executed.

above two task done repeatedly until while condition not return a false.
