What is Function and Why we need it?

In real life we take example of the TV remote.

In TV remote when we pressing Power button then TV get started and second time we press a power button then TV get off.

Basically Power task is define when press it TV on-off task or Function.
Function is similar kind when Function called Function do it's task.

Function is block of code which perform a particular task when it's called or invoked.

Function is used for code reusability.

Function is used for better code readability.

What is function parameter?

Parameter is variable which are declare at time of the function declaration inside function parenthesis.
It's scope is function scope. it's not accessible outside a function.
It's store or copy the value of the Actual Arguments.

What is function Actual Arguments?

When we are calling a function and passing some value as parameter it's called "Actual Arguments".

What is Default Parameter?

When we are calling function and function need value as parameter to perform it's task but we are not passing it's value that time we want function use Default value of that parameter then we use "Default parameter".

default parameters allow you to assign default values to function parameters.

If no value (or undefined) is passed for that parameter when the function is called, the default value is used instead.

Note:
❑ Only undefined triggers the default value.

❑ You can use expressions as default values. 

            
                // *Default Parameter

                function sum(a,b=0){
                    return a+b;
                }

                console.log(sum(1)); //* ans: 1
                console.log(sum(1,3)); //* ans: 4
