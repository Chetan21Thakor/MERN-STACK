Array In Javascript

What is Array and Why we need a Array?

If we are want to store multiple value in one single variable at contiguous memory location then we have to use Array.

Array is a special Type of Object which can store anything inside it.

Array is list (collection) of the multiple value or item which store in one single variable.

How to Create Array?

There are two way of creating a Array

  1. using Literal method
  2. using Constructor method

1.using Literal method

        
            //* literal method 

            let emptyArr=[];
            let nums=[1,2,3,4];
            let color=["pink",'red',"black","yellow"];
            let pair=[[1,2],[3,4],[5,6],[7,8],[9,0]];
            let person=["chetan",24,"software engineer"];
            let mixedArray=[1,2,3,"4","hi how are you?",{name :"chetan",age:21},[1,2,3,4,[1,2,3,]],hey,true,null, undefined];

2.using Constructor method

        
            //* using constructor method

            let array=Array(1,2,3);
            let array1=Array(20).fill(1);
            let array2=Array(20);

Note:

❑ Array constructor is mostly used when we want to create an empty array with the given length

Javascript Array is dynamic sized means it's size changed at run time and it's store n number element inside it.

Javascript Array is dynamic typed means you store any type of data inside it.also you can create mixedArray in js.

Array Indexing

Javascript Array has two type of Indexing

  1. Positive Indexing : it's start from 0.it's value increase left to right.
  2. Negative Indexing : it's start from -1. it's value decrease right to left.
