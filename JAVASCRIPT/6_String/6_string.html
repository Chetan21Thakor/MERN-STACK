String in JS

What is String.

In Normal word string is any textual data for example sentence, massage , password , any text it's called string.

String in javascript is collection of the unicode character.

In javascript any textual data which covered by Double Quot(" "),Single Quot (' ') or backticks (` `) it's a string.

String are Immutable in javascript. It's means you can't make any changes in original string.

Indexing in String

String has index.

String has two type of indexing.

Using index value you can access a string each character.

1.Positive index

Positive indexing start from 0 and end at n-1. 0 index means first character of the string. n-1 index means last character of the String


2.Negative index

Negative indexing start from -1 and end at -n. -1 index means last character of the string. -n index means last character of the String

Loops for String

String has a index so you can easily iterate on string and access a each character of the string.

We can use three Different loop on string.

  1. Normal loop
  2. for of loop
  3. for in loop
1. Normal loop

It's start from 0 index,end at n-1.

            
                for(let i=0;i< name.length;i++){

                console.log(name[i]);

                }
2. for of loop

It's used to iterate on the each character of the string.

            
                for(ch of str){

                console.log( ch);

                }
3. for in loop

It's used to iterate on the each index of the string.

            
                for(idx in str){

                console.log(idx);

                }
