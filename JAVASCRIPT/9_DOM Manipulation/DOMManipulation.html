What is DOM ? WHY need a DOM?

DOM stand for Document Object Model. When web page loaded on the browser then browser converted html into tree like structure called "DOM Tree".

browser converted HTML Document into nodes.Comments Convert into a CommentNode. extra space which we are add in html between two element or between opening and closing tag excluding a text it's store in textNode.

Each and everything in DOM Tree it's Nodes.

This DOM TREE Store in One js Object called "Document". Document object store all the data related a HTML document.
Making changes in html using this document object of the js it's called "DOM Manipulation".

  • We Need DOM Manipulation for Form validation using a Javascript.
  • We Need DOM Manipulation for Animation.
  • We Need DOM Manipulation for Change UI Dynamically based on data.It's called "Data Driven UI".

Selection Of HTML Element Using Document Object

There are 5 (five) methods of the document object which are used select element from html document ^

  1. document.getElementsByTagName("tagName")

    2. This method take tag Name as argument and return all the HTML element which created or available in html document using that particular tag name.

    It's return all element in HTMLCollection.
  2. document.getElementsByClassName("className")

    3. This method take class attribute value as argument and return all the element which HTML element class attribute value same as argument class name.

    It's return all element in HTMLCollection.
  3. document.getElementById("IdName")

    4. This method take id attribute value as argument and return first matched the element which HTML element id attribute value same as argument id name.

    It's return one Element.
  4. document.querySelector("IdName" or "tagName","className")

    5. querySelector("IdName" or "tagName","className") method is very PowerFull method.

    It's CSS Selector method internally it's use CSS Engine to select element from HTML document.

    Using this method you can select element from html Element using css all css selector. You just have to pass any css selector as argument.

    It's return one Element.

  5. document.querySelectorAll("Any css Selector")

    6. querySelector("IdName" or "tagName","className") method is very PowerFull method.

    It's CSS Selector method internally it's use CSS Engine to select element from HTML document.

    Using this method you can select element from html Element using css all css selector. You just have to pass any css selector as argument.

    It's return all Element in NodeList.

Manipulating CSS Of the Element using a JS DOM

How to change CSS of the HTML Element Using JS DOM

There are 5 Five way to change CSS of HTML Element.

  1. Using setAttribute() Method
  2. Using style property
  3. Using cssText property
  4. Using className property
  5. Using classList property

1.Using setAttribute() Method

setAttribute("style","cssProperty:value;")using a setAttribute() method you can direct set value for style attribute.

it's direct apply as inline css and if already inline css written for that particular element then this replace it.

2. Using style property

element.style.cssProperty="value"using this property you can direct access the css property inside js but make sure you are write css property in camel case not like css kebab case.

It's direct apply as inline css and if already inline css written for that particular element then this replace it.

3. Using cssText property

element.style.cssText="css Property:value;property:value;"using this property you can direct write css how you write inside a css file.

It's direct apply as inline css and if already inline css written for that particular element then this replace it.

4. Using className property

element.classNameThis property return all the class which set for that particular element in string by separating space.
Using this element.className Property we can set value for class also but remember one thing it's replace or remove all the old class name which set for that particular element.

first we write css for that class in css then we set that className using this element.className.

5. Using classList property

element.classListThis property return list or collection of all the class which set for that particular element in DOMTokenList.

element.classList This Property Provide 4 Method to add New class , remove any class which present already , toggle any class then last to check that element contain any class

  1. element.classList.add("className")

    2. This Method take name of the class as argument which you are to add in classList. It's not replace already present class it's just add new class only.

    One Time it's can add only one class.

  2. element.classList.remove("className")

    3. This Method take name of the class as argument which you are to remove from classList. it's just remove that particular class only.

    One Time it's can remove only one class.

  3. element.classList.toggle("className")

    4. This Method take name of the class as argument which you are to toggle in classList. It's not replace already present class it's just add new class only if not already present if already present then this method remove from classList.

    It's can remove or add a class.

  4. element.classList.contains("className")

    5. This Method take name of the class as argument and check it's present in classList or not if present then it's return true if not present then it's false.

    It's Just check class present or not.
