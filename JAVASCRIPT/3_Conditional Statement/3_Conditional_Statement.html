Conditional Statement

What is Conditional Statement and why we need it?

In Real life we are doing some task based on some specific condition or situation

for example
1.if today weather is cold then i drink a tea.
2.if today Cloud is raining then i will go office with umbrella.

in similar way if we need to do some task based on some specific condition then we need to use a conditional Statement.

A Statement or instruction which used to define a condition it's called conditional Statement.

if - else , if- else if -else, switch this all are conditional Statement in Javascript. and one Ternary Operator(? :). it's Operator not Statement.

if - else Conditional Statement

Syntax of if -else conditional Statement.

            
                let weather = "rainy";

                if (weather === "rainy") {
                console.log("take Umbrella.");
                } else {
                console.log("Enjoy Sunshine.");
                }
How if -else work.

execution of code run top to bottom line by line in if-else Statement.

First if check a condition which written inside a parenthesis. if this condition return true then a code which written inside if block it's executed and skip else block code. if this condition return false then else block of code executed.

if work on truthy and falsely value.

            if else Statement work from top  to bottom 

            step 1 : it's check a condition which is define inside a if statement .

            step 2: A condition is return "True" then if block of code is run or executed and skip else block of code.

            step 3: A condition is return "false" then else block of code is run or executed.
            else part is Optional if you want to skip to write else block you can skip.
            else always come with one if statement.

You can write a multiple if statement to check multiple condition.js engine check each if statement condition and any one of them return true then execute a that particular if block code. If all if condition return true then all if block of code execute. 

            
                let marks = 85;

                if (marks >= 50) {
                console.log("You passed.");
                }

                if (marks >= 80) {
                console.log("You got an A grade.");
                }

When you need to check multiple condition but execute any one if block code which if condition first return true then you have to use a if-else if -else conditional statement. 

            
                let score = 75;

                if (score >= 90) {
                console.log("Grade A");
                } else if (score >= 60) {
                console.log("Grade B");
                } else {
                console.log("Grade C");
                }

It's also executed from top to bottom same like if statement.
Here is some difference is if from top to bottom any one if condition return true then it's execute thatif block of code and skip bottom all else if block code although it's can be true.
else block code run only when above all condition return false.

Switch Statement

Syntax of Switch Statement.

            
                let day="Sunday";

                switch(day){
                    case "Monday":console.log("Working Day");
                                        break;
                    case "Tuesday":console.log("Working Day");
                                        break;
                    case "Wednesday":console.log("Working Day");
                                        break;
                    case "Thursday":console.log("Working Day");
                                        break;
                    case "Friday":console.log("Working Day");
                                        break;
                    case "Saturday":console.log("HoliDay");
                                        break;
                    case "Sunday":console.log("HoliDay");
                                        break;
                    default:console.log("Invalid day");
                }

switch keyword then () parenthesis inside this parenthesis test case variable which value is checked it's matched with any case. then code{}curly braces.Inside this {} define different case and last default case.

How switch statement work?

step 1 : switch statement first check test case variable value matched with any case.
step 2 : If it's matched then it's execute a that particular code which written in case.
step 3 : if after executing code which written in case if it's not find break statement then it's execute all the case which come after first matched case until default case just because of that after each case you must have to written a break statement.
break statement basically break or exit then control outside the switch statement it's help to stop execution after executing a matched case. step 4 : if test case variable not match with any case then only then default case is execute.

If want to multiple case share same code then you can use fall-through case. 

            
                //* example of  fall-through case

                switch(day){
                    case "Monday":
                    case "Tuesday":
                    case "Wednesday":
                    case "Thursday":
                    case "Friday":console.log("Working Day");
                                        break;
                    case "Saturday":
                    case "Sunday":console.log("HoliDay");
                                        break;
                    default:console.log("Invalid day");
                }

Switch Statement internally work on the "===" on strictly equal. it's also used Jump table for finding a case fast.

Ternary Operator

Syntax of Ternary Operator

            
                (condition) ? st1 : st2 ;
             
            
                let age=19;

               let result= (age >18 ) ? "adult": "not adult";

               console.log(result);

Ternary is Operator. it's not statement.After checking condition then based on condition it's return a result.

How Ternary Operator work?

step 1 : It's check condition.

step 2 : If condition return True then it's return result which immediately come after a question mark(?).
If condition return false then it's return a result which immediately come after colon (:).
